# 🎬 Movie Recommendation System using Gemini API

This project is an AI-powered **Movie Recommendation System** that generates **Top 5 personalized movie recommendations** based on user input such as favorite movies, genres, mood, or descriptions.  
It leverages **:contentReference[oaicite:0]{index=0}** to produce intelligent, natural-language recommendations.

---

## 🚀 Features

- 🎥 Generates **Top 5 movie recommendations**
- 🤖 Powered by **Google Gemini (Generative AI)**
- 🧠 Context-aware and personalized suggestions
- ⚡ Fast API-based response generation
- 🔌 Easy to integrate with Web / Mobile / Streamlit / React apps

---

## 🛠️ Tech Stack

- **Backend Language:** Python  
- **AI Model:** Gemini (via Google Generative AI API)  
- **Framework (optional):** FastAPI / Flask / Streamlit  
- **Frontend (optional):** React / HTML-CSS / Streamlit UI
